=== OpenSSL finding ===
The direct package chain is:
openssl-sys -> openssl -> solana-secp256r1-program -> solana-sdk.

The feature-level reverse tree additionally shows solana-client enabling
solana-sdk/openssl-vendored, which enables the vendored feature on
solana-secp256r1-program and openssl. solana-pubsub-client is present in the
larger Solana client graph, but it is not the sole source: claw-solana-core and
claw-wallet-engine also reach solana-sdk/solana-client directly. Removing only
the root workspace's direct solana-pubsub-client entry would therefore not
guarantee that OpenSSL disappears.

Phase 1 follow-up priority: audit and narrow the solana-client/solana-sdk feature
graph together with the existing solana-pubsub-client TODO. No dependency or
core-crate boundary was changed for this baseline. The current Windows build
workaround is documented in README.md.
